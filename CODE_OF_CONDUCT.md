# Code of Conduct

CollabSpace welcomes contributors with different backgrounds, experience levels, and viewpoints. We want project discussions and collaboration to remain respectful and useful.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and code without attacking people.
- Welcome questions and explain decisions in good faith.
- Give feedback that is specific, relevant, and considerate.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing someone's private information without consent.
- Insults, trolling, or repeated disruptive behavior.
- Any conduct that would make a reasonable contributor feel unsafe or unwelcome.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through the contact method listed on their GitHub profile. Do not post private or sensitive details in a public issue.

Maintainers may edit or remove comments, close discussions, or restrict participation when needed to keep the project safe and constructive. Reports will be handled as privately as practical.

This code applies to project spaces, issue and pull request discussions, and project-related events.
