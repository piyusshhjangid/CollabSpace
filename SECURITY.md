# Security Policy

## Supported versions

Until the project publishes versioned releases, security fixes target the default branch.

## Report a vulnerability

Please do not report vulnerabilities in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository if it is enabled. If it is unavailable, contact the repository owner privately through the contact method on their GitHub profile.

Include the affected area, the impact, steps to reproduce, and any safe proof of concept. Do not include real user data, credentials, or secrets.

Please allow the maintainer time to investigate and coordinate a fix before sharing vulnerability details publicly.
